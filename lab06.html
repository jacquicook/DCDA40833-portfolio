Reflection

For my basemap design, I wanted the map to look different from normal maps that are usually gray or plain. I chose a bright orange color for the land and used blue for the water so it would stand out. I also added simple colors for roads and buildings so the map would still be easy to read. My goal was to make the map look clean, colorful, and visually interesting while still showing the important features.

One challenge I faced when designing the basemap was thinking about how the map should look at different zoom levels. If too many things appear on the map at the same time, it can look messy and confusing. I decided to focus on the most important features like roads, water, and buildings. Larger features are easier to see when the map is zoomed out, while smaller details become more useful when the map is zoomed in closer. This helped keep the map clear and readable.

The technical part of the assignment was also challenging because I had to connect Mapbox with Python to create the interactive map. Sometimes the map did not display correctly, and it took time to figure out what was wrong. I had to make sure the style was published and that the access token and style ID were correct in the code. I used AI tools to help understand some of the coding steps and fix errors. This helped me complete the assignment and better understand how the tools work together.
