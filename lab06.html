Lab 6: Interactive Hometown Map

Interactive Map

Overview

  • Design a custom Mapbox basemap
  • Build an interactive hometown map using Python and Folium

Learned

  • How basemap design affects the look and readability of a map
  • How Python and Mapbox can work together to create an interactive map
  • How troubleshooting style IDs, tokens, and published maps is part of the mapping process

Skills

  • Python mapping
  • Mapbox customization
  • Interactive geographic storytelling

Reflection

For my basemap design, I wanted the map to look different from normal maps that are usually gray or plain. I chose a bright orange color for the land and used blue for the water so it would stand out. My goal was to make the map look clean, colorful, and visually interesting while still showing the important features. I am from Forth Worth and added 10 locations that were meaningful to me such as my favorite restaurant, favorite shopping area, etc.

This was the hardest lab for me in the course. Working with Mapbox and connecting it with Python took a lot of troubleshooting, and there were times when the map did not display the way I expected. Even though I was able to get the map working, I am still not completely sure that I achieved everything I originally wanted the map to show. However, the process helped me better understand how basemap design, styling, and interactive mapping work together.
